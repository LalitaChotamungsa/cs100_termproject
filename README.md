How to use
1.กด “create Profile”
2.กรอกข้อมูลพื้นฐาน เช่น ชื่อ สิ่งที่ชอบทำ สิ่งที่สนใจ สิ่งที่อยากเรียนรู้เพิ่มเติม
3.กด “create Portfolio” เพื่อsaveข้อมูล จากนั้น
4.กดเลือก Profile Portfolio ที่บันทึกไว้ จากนั้นกรอกข้อมูลให้ครบถ้วน และกด “Save Portfolio item”
ถ้าต้องการกดดู Portfolio ที่สร้างไว้ให้กด “View Portfolio”
